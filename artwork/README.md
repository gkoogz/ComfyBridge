# Application icon

`comfybridge.png` is the selected master artwork generated with the built-in image generation tool. `pack_icons.py` performs only resizing and ICO/container packaging with Pillow. The same mark is used by the Windows EXE/tray/monitor and Android launcher.

Generation prompt:

> Use case: logo-brand. Asset type: square application icon for ComfyBridge, an Android and Windows app connecting a phone to a PC for image and video generation. Design a polished minimal bold geometric bridge arch with two solid pillars and a small central play triangle integrated into the arch opening, mint green and pale icy cyan against a solid very dark midnight navy square. Crisp edges, exceptionally simple silhouette readable at 16 pixels, centered symbol occupying about 70 percent of square. Flat graphic with a very subtle mint to cyan gradient on symbol, no text, no letters, no tiny details, no borders, no mockup, no shadows outside icon, no other objects. Entire square is the finished icon artwork.
