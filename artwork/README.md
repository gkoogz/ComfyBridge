# Application icon

`comfybridge.png` is the selected master artwork, revised with the built-in image generation tool to the requested white outline cube and play button. `pack_icons.py` performs only resizing and ICO/container packaging with Pillow. The same mark is used by the Windows EXE/tray/monitor and Android launcher.

Generation prompt:

> Replace the current ComfyBridge app icon completely according to this exact simpler design: a solid white right-pointing play triangle inside a white outline cube. A single clean isometric wireframe cube, recognizable as a 3D cube, with thick white edge lines and a solid white play triangle centered clearly inside it. Keep a plain very dark midnight navy square background. The cube encloses the triangle, and cube edge lines must not run through the triangle. Minimal, flat, geometric, monochrome white symbol; crisp thick strokes readable at Windows tray size. Centered and comfortably padded, occupying about 70 percent of the square. No bridge arch, no green or cyan, no gradients, no text, no letters, no glow, no extra symbols, no mockup. Finished square application icon artwork.
